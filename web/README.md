# EduMerge Frontend (React Implementation)

A modern, high-performance frontend for the EduMerge Admission Management System, built with React 19, Vite, and TypeScript.

## 🚀 Key Features
- **Standalone Architecture**: Component-based design with modular services.
- **Unified Auth**: Centralized context-based authentication and role-based access.
- **Premium UI**: Handcrafted Vanilla CSS with glassmorphism and modern responsive layouts.
- **Real-time Validations**: Smooth form handling with real-time feedback and toast notifications.

## 🛠️ Tech Stack
- **React 19**: Standard for modern UI development.
- **Vite**: Ultra-fast build tool and dev server.
- **TypeScript**: Ensures type safety across the entire codebase.
- **React Router**: For client-side routing and layout management.
- **Axios**: Promised-based HTTP client for API communication.
- **Lucide Icons & Emojis**: Modern visual cues.
- **React Hot Toast**: Beautiful notification system.

## 📁 Folder Structure
```bash
/src
  /components  # Reusable UI parts (Sidebar, CustomSelect, etc.)
  /context     # React Context for global state (Auth)
  /pages       # Full page components (Dashboard, Login, etc.)
  /services    # API interaction logic (Admission, Applicant, etc.)
  /styles      # Global and component-specific styles
```

## ⚙️ Development Setup
1.  Install dependencies:
    ```bash
    npm install
    ```
2.  Start the development server:
    ```bash
    npm run dev
    ```
3.  Build for production:
    ```bash
    npm run build
    ```
